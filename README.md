# CAN-Based Vehicle Parameter Monitoring & Fault Diagnostic Dashboard

## Project Overview

This project is a browser-based dashboard for monitoring and visualizing vehicle parameters such as RPM, temperature, and voltage.

The project demonstrates the concept of CAN-based vehicle parameter monitoring using a web dashboard.

## Technologies Used

* HTML
* CSS
* JavaScript
* CAN Bus Concepts
* Visual Studio Code

## Features

* Vehicle parameter monitoring
* RPM display
* Temperature display
* Voltage display
* Live parameter visualization
* CAN bus monitoring concept
* Fault diagnostic visualization

## Current Implementation

The current version uses HTML, CSS, and JavaScript to create a browser-based vehicle monitoring dashboard with dynamically changing parameter values.
